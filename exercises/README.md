# 编程练习

在本目录填写函数，然后运行：

```bash
pytest tests/test_exercises.py -v
```

当前学生文件是空实现（`NotImplementedError`），测试会失败。  
参考答案在 `solutions/`，用于对照，请先自己写。

| 文件 | 目标 |
| --- | --- |
| `ex01_metrics.py` | 手写 accuracy 与混淆矩阵 |
| `ex02_train_step.py` | 补全一步训练 |
| `ex03_conv.py` | NumPy 二维卷积 |
| `ex04_overfit.py` | 判断过拟合并选择正则 |
| `ex05_cross_entropy.py` | 数值稳定的交叉熵 |
